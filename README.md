# pairwise-audio-ringbuffer-seek

拖动进度条到三分之二处，播放器先静音半秒再出声，环形缓冲的读指针跳转后写指针还在旧位置，中间那段被当成未填充；seek 到未解码区域时没有触发预取，播放停在缓冲末尾等待；缓冲区的可读区间用绝对值比较，回绕后 start 大于 end，整个缓冲被判为空；seek 时只重置了读指针没清解码器内部状态，重叠帧被重复输出，出现一段回声；快速连续 seek 时多个预取任务同时写同一段缓冲，后完成的覆盖前面的数据；缓冲区大小按采样点数配置，但按字节推进指针，读写速度差一倍，缓冲很快被填满；音频时钟在 seek 后没有重置，UI 进度条按旧时钟继续走；seek 到文件末尾附近时预取返回不足一帧，播放器直接判定流结束；暂停状态 seek 后恢复播放，缓冲里的静音填充被当作音频输出，开头有一声爆音；多声道交错存储时指针按帧推进但拷贝按采样推进，左右声道错位。media/audio_ringbuffer_seek.py 是核心，tests/test_audio_ringbuffer_seek.py 15个红。要修的是：读写指针原子切换；seek 触发预取；回绕归一；清解码器；预取版本号；按帧计；时钟重置；尾帧补齐；静音填充丢弃；按帧拷贝。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
